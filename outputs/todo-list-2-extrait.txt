17. Panier / Commande
1. Ajouter un ou plusieurs menus au panier.
2. Modifier le nombre de personnes.
3. Bloquer si inférieur au minimum.
4. Calculer :
○ prix menu ;
○ réduction ;
○ livraison ;
○ total.
5. Appliquer 10 % de réduction si la commande dépasse de 5 personnes le minimum.
6. Demander les informations de prestation :
○ nom ;
○ prénom ;
○ email ;
○ GSM ;
○ adresse ;
○ ville ;
○ code postal ;
○ date ;
○ heure.
7. Préremplir avec le compte connecté.
8. Ajouter la livraison :
○ gratuite ou normale à Bordeaux selon ton choix ;
○ hors Bordeaux : 5 € + 0,59 €/km si tu implémentes le calcul complet.
9. Bloquer la validation si champs obligatoires vides.
10. Enregistrer la commande en base.
11. Créer le statut initial.
12. Créer l’historique du statut.
13. Envoyer un email de confirmation.
14. Créer la page confirmation.
